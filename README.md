One line of software error copy that tells the user the brutal truth about what went wrong — the database crashed mid-save and swallowed their last changes — and makes them laugh on the way out, with a backup kept and a retry to pretend it never happened. Built for make.fun's "Say What Actually Broke" bounty, where a house judge picks the funniest, truest line.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
